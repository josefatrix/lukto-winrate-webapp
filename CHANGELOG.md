# Changelog

Todos los cambios notables de este proyecto serán documentados en este archivo.

El formato está basado en [Keep a Changelog](https://keepachangelog.com/es-ES/1.0.0/),
y este proyecto adhiere a [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.5.0] - 2026-01-19

### Añadido
- 📈 Gráfico de rendimiento en perfil de jugador
- 🎴 Tarjeta compartible para WhatsApp/Instagram
- 🔍 Búsqueda y filtros elegantes en ranking
- 🤝 Sección de rivales y aliados en perfil
- 💰 Sistema de apuestas con XP en predicciones
- 👥 Estadísticas de mejores duplas y tríos
- 📊 Comparación Head-to-Head entre jugadores
- 🏆 24 logros desbloqueables con descripciones
- 📱 Haptic feedback global en todos los botones

### Mejorado
- Iconos SVG personalizados (sin emojis)
- Touch response en toda la UI
- Chips de filtro elegantes para ordenar ranking

## [1.4.0] - 2026-01-18

### Añadido
- 🔮 Sistema de predicciones inteligente con probabilidades
- 📊 Cálculo de probabilidad basado en estadísticas de equipo
- Header minimalista rediseñado

### Mejorado
- Ganador opcional al crear partido (para predicciones)

## [1.3.0] - 2026-01-17

### Añadido
- 🎮 Sistema de XP y rangos (Bronce → Leyenda)
- 🏅 Jugador de la Semana y del Mes
- 📅 Filtros de tiempo (Todo, Mes, Semana)
- 🎯 Sistema de logros/badges
- 📊 Fórmula de ranking mejorada

### Mejorado
- Navegación tipo SofaScore
- Iconos SVG para rangos

## [1.2.0] - 2026-01-16

### Añadido
- 📱 PWA instalable
- 🌙 Modo oscuro/claro
- 🎊 Confetti para MVP
- ⏳ Skeleton loading
- 🔔 Notificaciones locales

### Mejorado
- Compatibilidad con iOS Safari
- Persistencia de Firebase mejorada

## [1.1.0] - 2026-01-15

### Añadido
- ⭐ Sistema de calificaciones por partido
- 🏆 Cálculo de MVP por partido
- 👤 Perfiles de jugador
- 🔐 Gestión de administradores
- 📊 Dashboard de admin

### Mejorado
- UI glassmorphism
- Transiciones suaves

## [1.0.0] - 2026-01-14

### Añadido
- 🎮 Registro de partidos
- 👥 Gestión de jugadores
- 📊 Estadísticas básicas (Win Rate, Victorias, Derrotas)
- 🔐 Autenticación con Google
- 🔗 Vinculación de usuarios con jugadores
- ☁️ Almacenamiento en Firebase
